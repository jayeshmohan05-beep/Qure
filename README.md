# QURE

Smart Hospital Patient & Queue Management System, an Android app built with Java, SQLite and Firebase.

QURE streamlines outpatient department workflows and reduces physical waiting-room congestion. It has three role-based portals (Patient, Doctor and Admin) so patients can book appointments and track their live queue token, while doctors and admins manage consultations and the queue.

## Features
- Role-based login for Patient, Doctor and Admin
- Browse departments and doctors, and book appointments
- Live queue tokens with status tracking
- Emergency priority handling in the queue
- Medical reports section
- Hospital locations
- Hybrid offline-first design: local SQLite with Firebase for cloud sync

## Tech Stack
- Language: Java
- UI: XML layouts, Material Design
- Local database: SQLite
- Cloud: Firebase (Authentication and cloud sync)
- IDE: Android Studio

## Getting Started
1. Clone this repository.
2. Open it in Android Studio and let Gradle sync.
3. Make sure `app/google-services.json` is present (needed for Firebase).
4. Run the app on an emulator or an Android device.
